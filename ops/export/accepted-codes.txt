#
# Formato: "<caminho><TAB><texto aceito><TAB><motivo>", uma entrada por linha; linhas vazias e as que começam com "#"
# são ignoradas. O caminho é um arquivo exato da árvore exportada (sem padrão); o texto aceito é o trecho exato que o
# detector acusaria, e a entrada aceita toda ocorrência dele no arquivo; o motivo é uma frase em português, sem código
# interno. Só a coluna do texto aceito fica fora da varredura: o caminho, o motivo e estes comentários são varridos.
#
# Cada entrada é necessária (casa pelo menos uma ocorrência na exportação) e cobre só referências funcionais: as
# que o código usa, nunca as de comentário, docstring ou mensagem, que a limpeza tira. Conferido por
